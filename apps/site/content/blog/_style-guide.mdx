<Takeaways>
- Posts are MDX files in `apps/site/content/blog`. The file name is the URL.
- Code blocks are rendered at build time by Expressive Code, so readers download no highlighter.
- `draft: true` keeps a post visible in `next dev` and out of the build.
</Takeaways>

## Text

Body text is set in Newsreader at a reading measure of about 70 characters; headings and interface text stay in Geist. Quotes are curled automatically, so "this" and 'that' come out right, `--` becomes an en dash -- and `---` becomes an em dash---without typing anything special.

You get **bold**, *italic*, `inline code`, [links](https://gthanasis.com) and ~~strikethrough~~. Keyboard shortcuts use a component: press <Kbd>⌘</Kbd> <Kbd>K</Kbd> to open the palette.

A sidenote sits in the margin on a wide screen and opens inline when tapped on a phone.<Sidenote>Like this one. Use them for asides that are too small for a paragraph and too useful to drop.</Sidenote> Footnotes work too, for references that belong at the end.[^1]

## Callouts

GitHub-style alerts, written as blockquotes:

> [!NOTE]
> Background the reader might need.

> [!TIP]
> A better way to do the thing.

> [!IMPORTANT]
> Something they must not skip.

> [!WARNING]
> This will bite if ignored.

> [!CAUTION]
> This is destructive or hard to undo.

A plain blockquote stays quiet:

> Simple things should be simple, complex things should be possible.

## Code

A file with a title, highlighted lines and inline marks:

```ts title="src/lib/retry.ts" {4-6} "attempt"
export async function retry<T>(fn: () => Promise<T>, tries = 3): Promise<T> {
  let lastError: unknown
  for (let attempt = 1; attempt <= tries; attempt++) {
    try {
      return await fn()
    } catch (err) {
      lastError = err
      await sleep(2 ** attempt * 100)
    }
  }
  throw lastError
}
```

A diff, with added and removed lines:

```ts title="src/lib/queue.ts" del={2} ins={3-4}
export function enqueue(job: Job) {

  queue.push(job)
}
```

## Tables and math

| Block | You write | Rendered by |
|---|---|---|
| Callout | `> [!TIP]` | remark-github-blockquote-alert |
| Footnote | `[^1]` | remark-gfm |
| Math | `$O(n \log n)$` | KaTeX |
| Code | a fenced block | Expressive Code |

Inline math like $O(n \log n)$ sits in the line; display math gets its own:

$$
p_{\text{fail}} = 1 - \prod_{i=1}^{n} (1 - p_i)
$$
